# Brokenhip Connector releases

Prebuilt binaries of the Brokenhip connector (built from BrutalSystems/brokenhip-be by `.github/workflows/connector-release.yml`).

Download the asset for your platform from the [latest release](../../releases/latest), run it in a terminal, and enter the pairing code shown on the data source's **Connector** tab in brokenhip.
